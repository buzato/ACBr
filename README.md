# ACBr (snapshot para o build do Wynix)

Espelho próprio, **não oficial**, de partes do [Projeto ACBr](https://projetoacbr.com.br/fontes/) (LGPL).
O ACBr só publica o fonte em SVN (`https://svn.code.sf.net/p/acbr/code/trunk2`) e os espelhos Git de terceiros
já sumiram (`MirrorProjetoACBr/ACBr`). Aqui ficam só as pastas que o build da ACBrLibNFe usa
(`Fontes`, `Projetos/ACBrLib/Fontes`, `Exemplos/ACBrDFe/Schemas`), em revisões fixas.

Cada revisão tem a tag `trunk2-r<revisão>`. Para criar uma nova, rode o workflow **Snapshot do SVN oficial do ACBr**
(Actions → Run workflow) informando a revisão. A licença e os avisos de copyright do ACBr permanecem nos arquivos.
